\begin{abstract}
Sliding-window attention (SWA) gives Transformers a constant per-step KV-cache and linear-time decoding, but information that leaves the window is lost irrecoverably; linear-attention and state-space models keep a constant-size recurrent state yet trade away the sharp local retrieval that softmax attention provides. We present \textbf{GMSWA (Gated-Memory Sliding-Window Attention)}, a single constant-memory attention layer that composes an exact local softmax window with a recurrent gated-delta-rule matrix memory. The two branches are \emph{complementary by construction}: the window attends only to the most recent $W$ tokens, while the memory ingests \emph{only tokens that have been evicted from the window}, so the two coverage sets partition the causal history with neither overlap nor future leakage. The layer's output mixes the two branches through a learned per-position gate, $o = \alpha\cdot\mathrm{SWA} + (1-\alpha)\cdot\mathrm{mem}$. A revised variant (v3) adds separate \emph{NoPE} (no positional encoding) content-retrieval projections for the memory branch, decoupling long-range associative recall from rotary position phase and yielding length extrapolation. The whole layer keeps a KV-cache and recurrent state whose size is \emph{independent of sequence length}. At 340M parameters trained on 10B tokens of FineWeb-Edu under a shared recipe, GMSWA-v3 attains the lowest next-token loss at every measured token position among constant-memory models, and the gap over plain SWA \emph{grows with distance}---direct evidence that the memory exploits far context. Beyond the 2048-token training length, a same-recipe full-attention Transformer collapses (loss 5.74 then 7.21 at the 2--4K and 4--8K bands, a rotary-extrapolation failure), whereas GMSWA-v3 remains the best of all four models (3.99, 4.04). On single-needle retrieval (NIAH/RULER) at this scale, GMSWA-v3 matches SWA---discrete recall is known to be scale-emergent and weak in sub-billion base models---so at 340M the memory delivers \emph{soft} long-context utilization (lower loss) rather than sharp discrete copy; we report this honestly and frame the predicted recall win as a scale-dependent, structurally motivated \pending{} result. A training-free capacity probe explains the design space: bilinear constant-memory mechanisms (linear/delta) hit a rank wall, motivating a recall-versus-memory frontier within which GMSWA is positioned. GMSWA is offered as a reference framework for SWA-based hybrid sparse attention with a pluggable, complementary constant-memory tail.
\end{abstract}

\section{Introduction}

\subsection{Problem and Motivation}
Standard self-attention costs $O(T^2)$ per sequence and, at inference, a KV-cache that grows linearly with sequence length $T$. For long-context decoding this makes memory and latency the binding constraints rather than compute. Two established families relax this cost, each with a structural blind spot.

\emph{Sliding-window attention} (Mistral, Longformer) caps attention at the most recent $W$ tokens, giving an $O(W)$ per-step cache that is constant in $T$ and an implementation that drops directly into existing Transformer stacks. Its limitation is definitional: any token that leaves the window is gone, so genuinely long-range dependencies cannot be served, at any model scale, by the window alone.

\emph{Linear-attention and state-space models} (Mamba, GLA, DeltaNet, Gated DeltaNet) carry a fixed-size recurrent state and reach arbitrarily far back in principle, but their bilinear state is a weak associative store: precise local retrieval---the operation softmax attention does effortlessly---degrades as the number of stored associations grows.

The two failure modes are complementary, which suggests composing rather than choosing. The natural questions are \emph{where} to attach a constant-memory recurrence to a window so the two do not duplicate work, and \emph{how} to make that memory retrieve content rather than position so it survives beyond the training length. This paper answers both.

\subsection{Research Questions}
\begin{itemize}
  \item \textbf{RQ1.} Can a single constant-memory layer combine an exact local window with a recurrent memory so that the memory measurably improves long-context modeling \emph{beyond} what the window alone achieves?
  \item \textbf{RQ2.} Does feeding the memory \emph{only evicted tokens} (a complementary, non-overlapping partition of history) and giving it \emph{content-based NoPE retrieval projections} produce graceful length extrapolation, in contrast to full attention's rotary-extrapolation collapse?
  \item \textbf{RQ3.} What is the honest reach of such a memory at small scale---soft loss-level utilization versus sharp discrete recall---and how is that explained by the capacity limits of bilinear constant-memory stores?
\end{itemize}

\subsection{Contributions}
This paper makes four contributions.
\begin{enumerate}
  \item \textbf{Architecture.} We introduce GMSWA, a constant-memory attention layer pairing an exact softmax sliding window with a gated-delta-rule matrix memory under a learned mixing gate. The defining choice is \textbf{complementary coverage}: the memory ingests only window-evicted tokens, so the window's exact-local set and the memory's long-tail set partition the causal prefix with no overlap and no future leakage (verified bit-exactly).
  \item \textbf{NoPE content retrieval for extrapolation (v3).} We add separate, position-free retrieval projections ($\mathrm{mem}_q$/$\mathrm{mem}_k$) for the memory branch, plus a corrected gate initialization. Decoupling associative recall from rotary phase is what lets GMSWA keep improving past the training length where rotary full attention fails.
  \item \textbf{Best-in-class constant-memory long-context utilization, with extrapolation beyond full attention.} Under a shared 340M/10B-token recipe, GMSWA-v3 has the lowest next-token loss at every measured position among constant-memory models, with a gap over SWA that widens with distance, and it is the single best model---better than full attention---in the extrapolation bands where rotary attention collapses.
  \item \textbf{A recall-versus-memory frontier and an honest scale account.} A training-free capacity probe shows bilinear constant memories hit a rank wall (storing $D$ associations needs $O(D^2)$ state) that a sketch/hash memory escapes ($O(D)$) but cannot be trained reliably; this frames a recall--memory design frontier and explains why, at 340M, GMSWA yields soft utilization rather than discrete recall, with the discrete-recall win predicted at larger scale where SWA remains structurally capped by its window.
\end{enumerate}

We position GMSWA not as a single point model but as a \textbf{reference framework} for SWA-based hybrid sparse attention with a pluggable, complementary constant-memory tail.

\section{Related Work}

\subsection{Sparse and Sliding-Window Attention}
Window attention \citep{longformer}; Mistral's SWA \citep{mistral_swa} bounds the attention span to recent tokens for an $O(W)$ cache and linear decoding. Blockwise and hierarchical sparse schemes extend the reachable span but still discard or compress distant context. GMSWA keeps an \emph{exact} local window---no approximation inside the window---and delegates the discarded tail to a recurrent memory rather than to a wider or sparser attention pattern.

\subsection{Linear Attention, SSMs, and Constant-Memory Recall}
Linear attention and selective state-space models (Mamba \citep{mamba2023}) maintain a fixed-size recurrent state for $O(1)$ per-step memory. The delta rule and its gated form (Gated DeltaNet \citep{gateddeltanet2024}) cast the update as one regularized least-squares step, sharpening associative writes; DeltaProduct \citep{deltaproduct2025} and RWKV-7 \citep{rwkv7_2025} extend the state transition's expressivity; Based \citep{based2024} interpolates between linear and local attention to recover recall. The Zoology study \citep{zoology2023} documents a recall--throughput tradeoff for these stores, and a test-time-regression view \citep{ttr2025} formalizes their effective capacity as bounded by the rank of the bilinear state---the rank wall we probe in the capacity-probe section. GMSWA uses a gated-delta-rule memory as its long-tail branch but, unlike pure linear/SSM models, never asks that branch to do local retrieval: the exact window owns the local regime.

\subsection{Window-plus-Memory Hybrids, and How GMSWA Differs}
The closest prior art combines a window with a constant-memory side channel. \textbf{laLTE} \citep{lalte2025} couples SWA with linear attention and a \emph{learned token-eviction} policy; \textbf{SWAX} \citep{swax2025} pairs SWA with an xLSTM recurrence. Titans \citep{titans2025} learns to memorize at test time, and Fast-weight Product-Key Memory (FwPKM) \citep{fwpkm2026} builds a high-capacity differentiable key--value store that outperforms Gated DeltaNet on its mechanism benchmark. GMSWA differs along three axes that we make explicit and ablate:
\begin{enumerate}
  \item \textbf{Complementary, eviction-defined coverage.} The memory consumes \emph{exactly and only} the tokens evicted from the window. The window's set $[t{-}W{+}1, t]$ and the memory's set $[0, t{-}W]$ partition the prefix; there is no overlapping double-coverage of recent tokens and no learned router deciding what to memorize. This is a deterministic division of labor, not a learned gate over which tokens enter memory (contrast laLTE's learned eviction).
  \item \textbf{NoPE content retrieval.} Separate position-free $\mathrm{mem}_q$/$\mathrm{mem}_k$ projections make the memory retrieve by content, decoupled from rotary phase---the mechanism behind GMSWA's extrapolation past the training length.
  \item \textbf{A recall--memory frontier as design science.} Rather than claim a new highest-capacity mechanism (a space we find both occupied by FwPKM and hard to train), we characterize \emph{where on the recall--memory frontier} a window+memory layer should sit, and offer GMSWA as a reference instantiation.
\end{enumerate}

\subsection{Gap This Paper Addresses}
Prior window+memory hybrids either (i) let the memory and window overlap in coverage, (ii) leave the memory position-coupled (so it inherits rotary's extrapolation failure), or (iii) chase a single best mechanism. GMSWA closes these by a deterministic complementary partition, NoPE content retrieval for extrapolation, and a frontier framing that is honest about the scale at which discrete recall emerges. Benchmarking against laLTE/SWAX/FwPKM and against same-recipe SWA, Gated DeltaNet, full attention, GLA, and Mamba-2 is the empirical core, with several entries \pending{}.

\section{Method}

\subsection{Overview}
Each GMSWA layer runs two parallel branches on the hidden state and fuses them with a learned, per-position sigmoid gate $\alpha_t$:
\begin{equation}
o_t = \alpha_t \, o_{\mathrm{local}}[t] + (1-\alpha_t)\, o_{\mathrm{mem}}[t].
\label{eq:mix}
\end{equation}
The local branch is exact causal SWA; the memory branch is a constant-size matrix fast-weight updated by a gated delta rule. The branches share a single small fusion projection $\mathrm{Linear}(d, 3H)$ producing, per head, the write strength $\beta$, the log-decay $g$, and the mixing coefficient $\alpha$.

\subsection{Local Branch --- Exact Sliding-Window Attention}
Each position $t$ attends only to the most recent $W$ tokens:
\begin{equation}
o_{\mathrm{local}}[t] = \mathrm{softmax}\!\left( \frac{q_t \, K_{[t-W+1:t]}^\top}{\sqrt{d}} \right) V_{[t-W+1:t]}.
\label{eq:swa}
\end{equation}
Queries and keys carry rotary position encoding. The implementation calls \texttt{flash\_attn\_func(causal=True, window\_size=(W$-$1, 0))} where available and falls back to an equivalent SDPA $+$ additive-mask path (e.g.\ in fp32 environments) producing identical results. The per-step local cache is a ring buffer of size $W\,H_{kv}\,2\,d$, constant in $T$.

\subsection{Memory Branch --- Gated-Delta-Rule Matrix Fast Weight}
Each query head holds a matrix state $S \in \mathbb{R}^{d\times d}$. A token is written to memory \emph{only when it is evicted from the window}---i.e.\ when it transitions out of $[t{-}W{+}1, t]$. On eviction of token $e$ with (pre-RoPE content) key $\hat{k}_e$ and value $v_e$, the state updates by a gated delta rule (the Gated DeltaNet / Mamba-2 form):
\begin{equation}
S_t = e^{g_t}\!\left( S_{t-1} - \beta_t\, S_{t-1}\hat{k}_e \hat{k}_e^\top \right) + \beta_t\, v_e \hat{k}_e^\top.
\label{eq:delta}
\end{equation}
Reading is linear-attention style: $o_{\mathrm{mem}}[t] = S_t\,\hat{q}_t$. Training uses FLA's chunk-parallel Triton kernel \texttt{chunk\_gated\_delta\_rule} (with exact backward); single-token decoding uses a lightweight inline path to avoid kernel-launch overhead. The memory state size is $H_q\,d\,d$, constant in $T$.

\subsection{Complementary Coverage: Eviction $=$ Write, No Overlap, No Leakage}
The defining property of GMSWA is that \emph{being evicted from the window is exactly the event that writes a token to memory}. As a result, at any step $t$ the memory set $[0, t{-}W]$ and the window set $[t{-}W{+}1, t]$ are disjoint and together cover $[0, t]$ exactly: no token is double-counted, and no future token can influence an earlier output. We verify this with a \texttt{test\_causality\_no\_future\_leak} check---perturbing the last position's input leaves every earlier position's output bit-for-bit unchanged---and with prefill/decode consistency tests (cosine $1.0$ after a decoding-cache bug fix described in the Results section). This deterministic partition is the structural distinction from hybrids whose memory and window can overlap or whose eviction is learned.

\subsection{NoPE Content-Retrieval Projections (v3)}
In v2, the memory reused the rotary-encoded keys/queries, coupling associative recall to position phase. \textbf{v3} introduces separate, position-free $\mathrm{mem}_q$/$\mathrm{mem}_k$ projections (NoPE) feeding the memory branch, so the memory retrieves by \emph{content}, independent of how far back the match lies. Combined with a corrected gate initialization (the memory contributes negligibly at initialization, $\alpha \approx 0.98$, so training begins near pure SWA and stays stable, then learns to lean on memory), this is the mechanism behind GMSWA-v3's length extrapolation: content matches do not decay with rotary phase, so the memory keeps helping past the training length where the rotary window's relative positions become out-of-distribution.

\subsection{Constant-Memory Analysis}
The per-layer inference state is the sum of the local ring buffer and the matrix memory, both independent of $T$ (Table~\ref{tab:mem}).

\subsection{Why a Bilinear Memory: the Rank-Wall Framing}
The memory's capacity is governed by the rank of its bilinear state. Under the test-time-regression view \citep{ttr2025}, a delta-rule store reconstructs values by regression against stored keys; storing $D$ near-orthogonal associations therefore requires state rank $\approx D$, i.e.\ $O(D^2)$ entries for $D$ associations. This rank wall (probed directly later) is \emph{why} we do not ask the memory to perform sharp local retrieval---that is the window's job---and is the reason GMSWA's memory is best understood as a \emph{soft} long-range summarizer at small scale. The frontier interpretation (recall vs.\ memory budget) follows in the discussion.

\section{Experimental Setup}
\textbf{Models.} Four architectures trained under one recipe at 340M parameters: \textbf{SWA} (pure window), \textbf{GMSWA-v2}, \textbf{GMSWA-v3}, and a \textbf{full-attention Transformer} (an upper-bound reference within the training length). A same-recipe \textbf{Gated DeltaNet} baseline (memory-only, no window; ${\sim}336$M, parameter-aligned) is \pending{} (training in progress); \textbf{GLA} and \textbf{Mamba-2} peers are \pending{}.

\textbf{Training.} 10B tokens of FineWeb-Edu \citep{finewebedu}; identical optimizer, schedule, tokenizer, and 340M shape (hidden 1024, 24 layers, 16 query / 4 KV heads, window 512) across models; training context length 2048. (A 110M development configuration with window 128 is used only for unit/consistency testing.) The 1B configuration (hidden 2048, 24 layers, 32/8 heads, window 512; 1218M params) is used for the \pending{} recall experiment.

\textbf{Evaluation.}
\begin{itemize}
  \item \emph{Loss vs.\ token position} (clean pretraining long-context utilization): next-token loss aggregated by absolute position band, including bands beyond the 2048 training length to test extrapolation. Lower is better.
  \item \emph{Single-needle retrieval} (NIAH / RULER \citep{ruler2024}): exact-match recall versus context length.
  \item \emph{Mechanism capacity probe}: a training-free diagnostic of constant-memory associative capacity.
\end{itemize}

\textbf{Reproducibility.} Configs and eval scripts are in the project repository (\texttt{flash-linear-attention/flame/configs/}, \texttt{eval\_results/}). The GMSWA layer is ${\sim}481$ lines; 13/13 unit tests pass (forward shapes, no NaN/Inf, full-parameter gradients, GQA, bit-exact causality, constant decode-time state, prefill$=$full-forward, step-decode$=$full-forward). Implemented with FLA \citep{fla}.

Two findings stand out.

\textbf{Within training length, GMSWA-v3 beats SWA at every position, and the margin grows with distance} (0.08 at 0--512, rising to 0.12 at 1024--2048). \textbf{Beyond the training length, full attention collapses while GMSWA-v3 is the single best model.} At 2--4K and 4--8K, the rotary Transformer's loss jumps to 5.74 then 7.21---a rotary-extrapolation failure---whereas GMSWA-v3 degrades gracefully (3.99, 4.04) and leads all four models. GMSWA thus inherits SWA's extrapolation robustness \emph{and} adds long-range modeling, at constant memory. This is the paper's most consequential result.

\section{Mechanism Capacity Probe}
\label{sec:probe}
To explain \emph{why} the memory behaves as a soft summarizer at small scale and to map the design frontier, we run a training-free diagnostic that removes optimization confounds. We store $D$ key$\rightarrow$token associations in a fixed-size state, query each key, decode the retrieved code against a shared codebook, and measure exact-token recall versus $D$ at \emph{equal} state size.

\begin{itemize}
  \item \textbf{Bilinear stores (linear attention, delta rule).} Capacity is bounded by the state rank: storing $D$ near-orthogonal associations needs $\approx O(D^2)$ state, so recall falls as load $D$ rises---the \textbf{rank wall}.
  \item \textbf{Hash / sketch store.} Capacity is set by the number of buckets, decoupled from the value dimension: $D$ associations need $\approx O(D)$ state, so it escapes the rank wall, with the advantage growing under load (illustratively, at high load the hash store retains markedly higher exact-token recall than the bilinear stores at equal state).
\end{itemize}

The qualitative finding---a hash/sketch memory's capacity advantage over linear/delta widens with load---confirms the bilinear rank wall as the operative constraint. \textbf{Important honest caveat.} The hash/sketch memory that \emph{wins on capacity} is hard to \emph{train}: across MQAR variants, hard-routing gives poor gradients and soft-routing collapses back to a low-rank store (a long-documented hard-vs-soft addressing problem). GMSWA's deployed memory is the trainable gated-delta-rule store; the probe explains its soft-utilization behavior and locates it on the recall--memory frontier.

\section{Analysis and Discussion}

\subsection{The Recall--Memory Frontier}
The probe and the model results describe one frontier. On one axis is \textbf{memory budget} (state size, held constant here); on the other is \textbf{discrete recall capacity}. Bilinear constant-memory stores sit below a rank-wall ceiling; sketch stores raise the ceiling but are not reliably trainable; an exact window has perfect recall \emph{within} its span and zero beyond it. GMSWA composes the two regimes---exact recall inside the window, soft trainable summarization outside---and the loss-vs-position curves show the composite improving on both pure SWA and, beyond the training length, on full attention. The frontier framing also predicts the scale dependence: as model scale lifts the memory off the rank-wall floor for the associations that matter, the soft-utilization advantage should sharpen into discrete recall (the 1B test).

\subsection{Why Extrapolation Works}
Full attention's collapse beyond 2048 is a rotary-phase failure: relative positions past the training length are out-of-distribution. GMSWA sidesteps this twice---the window only ever sees in-distribution relative offsets ($\le W$), and the memory retrieves by \emph{content} through NoPE projections, independent of how far back the match lies. The composite therefore degrades gracefully where rotary attention breaks, explaining GMSWA-v3's best-of-all standing in the extrapolation bands.

\subsection{Honest Scale Caveat}
The central honest point: at 340M, GMSWA's memory delivers \textbf{soft} long-context utilization (lower loss at every position, widening with distance) but \textbf{not} sharp discrete recall (NIAH ties SWA). This is consistent with the scale-emergence of discrete recall in base models and with the rank-wall capacity analysis. We do not claim a discrete-recall win at 340M; we claim a real, measured loss-level win and a structurally motivated, scale-dependent prediction for discrete recall that the 1B run is designed to test.

\subsection{Positioning: a Reference Framework}
Given that the \emph{highest-capacity mechanism} niche is both occupied (FwPKM \citep{fwpkm2026}) and, in our hands, hard to train, GMSWA's contribution is deliberately at the architecture/framework level: a window with a \textbf{pluggable, complementary, content-retrieving} constant-memory tail, characterized on the recall--memory frontier. We offer it as a basis on which different memory mechanisms can be dropped in and compared under a fixed, fair window+memory interface.

\section{Acknowledged Limitations}
\begin{enumerate}
  \item \textbf{Discrete recall at 340M is a tie, not a win.} The memory's benefit at this scale is loss-level utilization; the discrete-recall claim is explicitly \pending{} at 1B.
  \item \textbf{Key baselines are not yet in.} Same-recipe Gated DeltaNet, the evicted-only vs.\ memory-on-all ablation, and GLA/Mamba-2 peers are \pending{}; their absence limits how strongly the ``window's value'' and ``complementary design'' claims can be asserted today.
  \item \textbf{Efficiency numbers are partial.} Per-layer state is provably constant, but 340M wall-clock/throughput with \texttt{torch.compile}/CUDA-graphs is \pending{}.
  \item \textbf{Mechanism probe is a diagnostic, not a deployed component.} The capacity-winning hash memory is not trainable in our setup; conclusions from it bound the design space rather than the shipped model.
  \item \textbf{Single corpus / single scale family.} Results are FineWeb-Edu at 340M (plus a queued 1B); breadth across corpora and downstream tasks is future work.

\section{Conclusion and Future Work}
GMSWA is a constant-memory attention layer that composes an exact local softmax window with a complementary, content-retrieving gated-delta-rule memory fed only by window-evicted tokens. At 340M/10B tokens under a shared recipe, it achieves the lowest next-token loss at every measured position among constant-memory models---with a margin over SWA that grows with distance---and it is the single best model beyond the training length, where rotary full attention collapses. It does this at a per-layer state size independent of sequence length. We are honest that, at this scale, the win is soft long-context utilization rather than sharp discrete recall, and we explain that gap through a rank-wall capacity analysis and a recall--memory frontier. Future work fills the \pending{} cells: the 1B discrete-recall experiment, same-recipe Gated DeltaNet / GLA / Mamba-2 baselines, the evicted-only vs.\ memory-on-all ablation, a recall-vs-memory-budget frontier sweep, and fused-kernel efficiency numbers. We release GMSWA as a reference framework for SWA-based hybrid sparse attention with a pluggable, complementary constant-memory tail.
